ITERATION 6 - RUN AND TEST

This is the complete integrated system: React/Vite frontend, FastAPI backend,
local semantic processing, local Ollama verification, reports, downloads, and
manual-review cards.

1. Start Ollama in a separate terminal:
   ollama serve

2. In a first PowerShell terminal, open:
   D:\minor_project_iterative_approach\iteration_06_frontend_final_integration\project

   First-time setup only:
   py -3.13 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements-web.txt

   Then run:
   .\.venv\Scripts\Activate.ps1
   python run_backend.py

3. In a second PowerShell terminal, open:
   D:\minor_project_iterative_approach\iteration_06_frontend_final_integration\project\frontend

   First-time setup only:
   npm install

   Then run:
   npm run dev

4. Open the localhost address printed by Vite, normally http://localhost:5173.
